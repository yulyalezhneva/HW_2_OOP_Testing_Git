Описание проекта:

Создание класса Ingredient, который представляет собой базовую единицу рецепта – отдельный продукт или компонент блюда (мука, яйца, масло и т.д.). Он нужен для того, чтобы хранить информацию о каждом продукте, его количестве и единицах измерения.

Создание класса Recipe, который представляет собой рецепт одного блюда. Он нужен для того, чтобы объединить название блюда с набором ингредиентов, которые для него требуются, а также предоставить методы для работы с этими ингредиентами.

Создание класса ShoppingList, который представляет собой список покупок, который включает ингредиенты из одного или нескольких рецептов, и нужен для того, чтобы автоматически суммировать все необходимые продукты перед походом в магазин, учитывая, что разные рецепты могут использовать одни и те же ингредиенты.

Создание класса DietaryRecipe, который является наследником класса Recipe и представляет рецепт с указанием диетической категории.
